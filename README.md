# VisionTag AI: E-Commerce Image Classifier

VisionTag AI is a deep learning pipeline built to automate retail product image classification.
It leverages computer vision to categorize raw inventory, eliminating manual data entry.
**Tech Stack:** Python 3, TensorFlow, Keras, NumPy, and Matplotlib.
**Dataset:** Fashion MNIST (60,000 training images, 10 distinct apparel categories).

## Installation & Usage

1. Clone repository: `git clone [https://github.com/username/visiontag-ai.git](https://github.com/username/visiontag-ai.git)`
2. Install dependencies: `pip install tensorflow matplotlib numpy`
3. Run the pipeline: `python main.py`
**Impact:** Reduces operational bottlenecks and accelerates go-to-market timelines.
